# Facebook Lead Form Mockup

Construa um Mockup de um HTML com um formulário simples (3 campos: nome, email e telefone), com um endpoint vazio.

Esse formulário vai ser anexado em uma campanha de teste do Facebook forms (https://www.facebook.com/business/help/983639606486840), também conhecido como lead com formulário no site. Por isso, deve seguir as práticas solicitadas pela Meta.

Use a menor quantidade possível de códigos/arquivos
